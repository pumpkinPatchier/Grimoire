# Grimoire

https://github.com/pumpkinPatchier/Grimoire

This is a project I made many years ago.


## Description

A tool for creating, storing, organizing, and displaying spells for D&D5e. Made in Java. Runs in terminal.

## How to Use

Either use the text prompts or input spells using text files (all the `.txt` files showcase good inputs except the cleverly-named `bad_input.txt` file)

### Linux
Given that you have Java installed,

```
git clone https://github.com/pumpkinPatchier/Grimoire.git
cd ~/Grimoire
java Main.java
```

### Windows and Mac
I have never used Java on Windows or Mac so you are on your own for this one.

## Motivation
I created this many years ago for a school project. I remember racing to finish this before the "early-due-date" in order to get a bonus 5% for my overall grade. I ended up getting a 105% mark in the course, which my 3rd year CS highschool teacher noted was the only time that has happened before and personally apologized for the fact that it was impossible to print on the report card.

I remember this project served me well as a former Dungeon Master. Looking back on this project, I can see how it went beyond the course curriculum and requirements, and I can also understand why I was always so busy in highschool. I have data, and so long as there is data, I will eventually experience compulsion to categorize and assimilate everything into neat and tidy datastructures that can be easily sorted, accessed, replicated, and constructed. And ensure that it can be done in the terminal as well.

But I want to share this project to show that hard work does not have to go nowhere. It is recognized and acknowledged by those who understand the labour of trying to make an ASCII table print nicely in the terminal (I apologize for giving the teacher the idea because I am hearing that he added it as an option for bonus marks and it makes people rip their hair out to try and make a table work).

I am finding very often that people are less inclined to do the things that they want to do because somewhere, a machine has already done it better. But I don't care about the machine that does it nearly as much as I care about the process of me understanding it.

This project demonstrates an understanding of data structures, classes, object-oriented programming, sorting algorithms, file handling, error handling, command-line interfacing, regular expressions, ANSI escape code, and et cetera.To me, this project represents enthusiasm and eagerness to learn and create, and to add personal flourish and care to creation even when there is no benefit. Because I look at this today some years later and know that I see how hard I worked, even if my report card doesn't, and that's good enough for me.
